# ListaUsuarios

**ListaUsuarios** es una aplicación web desarrollada con Java y Spring Boot que permite mostrar una lista de usuarios en una interfaz web sencilla. El proyecto está diseñado siguiendo el patrón MVC (Modelo-Vista-Controlador).

## 🚀 Características

- Visualización de una lista de usuarios.
- Estructura modular usando controladores, modelos y vistas.
- Arquitectura basada en Spring Boot.
- Gestión de dependencias mediante Maven.

## 🛠 Tecnologías utilizadas

- Java 11+
- Spring Boot
- Maven
- Thymeleaf
- HTML
